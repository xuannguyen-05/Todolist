TODO LIST APPLICATION (NodeJS + MongoDB)

📖 Giới thiệu

      Ứng dụng Todo List gồm 3 level:
      
      Level 1: Xây dựng API backend
      
      Level 2: Giao diện EJS
      
      Level 3: Phân quyền admin / normal

🛠 Công nghệ sử dụng
  
      NodeJS
      
      ExpressJS
      
      MongoDB
      
      Mongoose
      
      EJS
      
      Bootstrap
      
      bcrypt

🚀 Chức năng

✅ Level 1

      Đăng ký user (hash password)
      
      Username không trùng
      
      1 user có nhiều task
      
      Lấy tất cả task
      
      Lấy task theo username
      
      Lấy task trong ngày
      
      Lấy task chưa hoàn thành
      
      Lấy task của user có họ "Nguyễn"

✅ Level 2

      Giao diện thêm task
      
      Xóa task
      
      Tick hoàn thành
      
      Progress bar

✅ Level 3

      Role: admin / normal
      
      Admin phân task cho normal
      
      1 task nhiều người hoàn thành
      
      Task chỉ done khi tất cả hoàn thành

⚙ Cách chạy project
npm install
npm start

Truy cập:

http://localhost:8080
